Драйвери для MACHINIST E5-MR9A · Xeon E5-2695 v4 · Radeon RX 570 (macOS)

Пакет ставиться вже після встановлення macOS на комп'ютер, що завантажується через OpenCore з цього репозиторію.

  • Вбудований звук (VoodooHDA 3.6.8) — лише на macOS 26 і новіших: Apple прибрала AppleHDA, тож звук плати (Realtek ALC897) дає VoodooHDA. На macOS 15 і старіших нічого не ставиться.
  • Спершу BIOS: контролер звуку має бути увімкнений — IntelRCSetup → PCH Configuration → Onboard Azalia → Enabled. Якщо він вимкнений, macOS його не бачить і драйверу нема з чим працювати.

Звук через HDMI відеокарти, USB-пульти (Behringer WING) і карти Blackmagic працюють і без цього пакета.

Журнал встановлення: /var/log/mr9a-drivers-install.log.
